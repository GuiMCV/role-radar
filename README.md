# Como Executar

1º - É necessário a instalação de dependências do projeto, como o Node.js, PrimeReact, Axios, Bootstrap.
2º - Você deverá substituir as chaves das APIs dentro do arquivo src/utils/chaves.js, esse chaves vc irá poder resgatar ao criar uma conta gratuita no Geoapify - https://myprojects.geoapify.com e no PrimeReact - https://primeui.store/
3º - Logo após, você já poderá rodar a aplicação, onde você irá acessar o terminal e rodar o comando "npm run dev", isso irá gerar um link de local host, onde você poderá acessar em seu navegador.
4º - É muito importante para o funcionamento do projeto, que você permita que o site tenha acesso à sua localização, caso contrário, a aplicação não rodará e irá apresentar uma mensagem de erro.
